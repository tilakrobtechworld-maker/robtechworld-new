# Rob Tech World — React conversion

This Vite + React project converts the supplied single-page HTML into React components and CSS. It keeps the responsive layout and GSAP/ScrollTrigger interactions, including the scroll-based color changes, word reveals, parallax cards, pinned horizontal case-study rail, counters, process timeline, service tabs, and reduced-motion support.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The project uses React 18, Vite, and GSAP. The brand mark is recreated as an inline SVG so it stays self-contained and editable.
